# Python — Dicionários e Estruturas Condicionais

Repositório dedicado à prática de conceitos fundamentais de Python por meio do desenvolvimento de um sistema escolar simples para registrar dados de alunos e analisar resultados acadêmicos.

## Conteúdos abordados

- **Dicionários:** organização de informações utilizando estruturas de chave e valor.
- **Entrada de dados:** coleta de informações por meio da função `input()`.
- **Tipos de dados:** utilização de strings e números decimais.
- **Estruturas condicionais:** aplicação de `if` e `else` para verificar condições.
- **Operadores relacionais:** comparação de notas para determinar a situação acadêmica.
- **F-Strings:** formatação e apresentação de informações dinâmicas.
- **Módulos da biblioteca padrão:** utilização de `datetime` para obter e formatar a data atual.
- **Saída de dados:** apresentação organizada dos resultados no terminal.

## Projeto desenvolvido

O programa simula um sistema escolar que recebe o nome e a nota final de um aluno, identifica a disciplina, verifica se a nota atende ao critério de aprovação e apresenta um resumo com os dados registrados e a data atual.

## Objetivo

Aplicar estruturas de dados, lógica condicional e formatação de informações em um exemplo prático, fortalecendo os fundamentos da programação com Python.

- Python 3
